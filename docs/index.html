给万象拼音
补上主流输入法的习惯

jvede
  1. 1觉得
  2. 2觉
  3. 3巨额
  4. 4决
  5. 5绝

以前第一候选是「巨额的」，现在是「觉得」。

v 当 ü、儿化音、模糊音、乱序纠错，外加科技、游戏、诗词词库。全部本地运行。

安装 看源码

修好的四件事

jve

v 当 ü

jve、jvan、jvn 直接当 jue、juan、jun 用，不再拆成 jv 加 e。q、x、y 同样处理。

huar

儿化音

结尾的 r 就是「儿」：huar 出花儿，yihuir 出一会儿，dianr 出点儿。

zi / zhi

模糊音

平翘舌、n 和 l、前后鼻音共六组，默认打开。打不准的音也能落到想打的字上。

zhonggup

乱序纠错

字母顺序打乱、相邻键按错时追加纠错候选。只在你打错时出现，正常输入不打扰。

安装

  1. 克隆仓库。
  2. 运行安装脚本。它会备份原文件、复制配置和词库，并在主词库里登记。
  3. 重新部署，重启输入法。
git clone https://github.com/OneLastHuman/wanxiang-pinyin-kit.git
cd wanxiang-pinyin-kit
bash install.sh

需要已安装万象拼音。诗词库约 16 MB，按仓库文档单独下载。

词库
